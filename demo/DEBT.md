## 動かし方（手元）

```
cd ~/src/product/ai-hack/demo
pnpm install
pnpm wrangler d1 migrations apply ai-hack-sekiari --local   # 手元の D1 を作る（種データ込み）
pnpm dev --port 3100
```

- 店の鍵は `node scripts/seed.mjs > migrations/0002_seed.sql` のときに乱数で作られ、`.store-key.local`（git の対象外）に平文で書かれる。店側の画面は `http://localhost:3100/store?key=<その鍵>`
- OrcaRouter を使うには `.env.local` と `.dev.vars` に `ORCAROUTER_API_KEY=...`。無ければ規則による読み取りと定型文で動き、画面にそう表示する
