## 3. 設計（`design.md`）

各節の食い違いをその場で直し、まとまった決めは末尾の節「2026-09-25 の監査の直し」に書いた。とくに前の版と逆になったもの:

- **完了済みの表示の幅**: 3時間 → 30分（実装に揃えた。3時間へ戻すかは本人・不具合-18）
- **`getPublicConfig()`**: 「1回取ってメモリに持つ」→「持たない」（実装に揃えた・設計-06）
- **Web プッシュの送信**: 「応答を返したあと（`waitUntil`）」→「応答の前に済ませ、1回4秒で打ち切る」（不具合-08）
- **Turnstile の許すホスト名**: 「公開先と `localhost`」→「公開先だけ。手元は試験用の鍵」（安全-23）
- **セッション**: 25時間の延長に加えて、作ってから14日で必ず切れる（安全-08）
- **店のホームの取り直し**: 画面が隠れても止めない（店-08）
- **入口の一覧**: 後から足した入口（`fetch/stream`・`place`・`place-suggest`・`store-image`・`store/email`・`admin/email`・`admin/password`）を載せた（設計-12）
- **使っていない列**: `accounts.failed_count`・`accounts.locked_until`・`stores.stripe_customer_id` は「予約・未使用」と書いた（0001 は本番に当たっているので消さない・設計-12）
